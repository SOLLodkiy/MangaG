# Как добавить мангу на сайт MangaG

Сайт сам находит главы и страницы в этой папке. Ничего устанавливать и
программировать не нужно: достаточно Проводника и (иногда) VS Code.

## Что уже есть

| Папка                | Что внутри                                                         |
| -------------------- | ------------------------------------------------------------------ |
| `pepper-and-carrot/` | **Настоящий комикс** «Перчинка и Морквик» (4 главы, лицензия CC BY) |
| `demo-north-wind/`   | демо-манга, нарисованная программно                                 |
| `demo-neograd/`      | демо-комикс, нарисованный программно                                |
| `jujutsu-kaisen/`    | **пустая заготовка** «Магическая битва»                            |
| `chainsaw-man/`      | **пустая заготовка** «Человек-бензопила»                           |
| `solo-leveling/`     | **пустая заготовка** «Поднятие уровня в одиночку»                  |
| `one-piece/`         | **пустая заготовка** «Ван-Пис»                                     |
| `attack-on-titan/`   | **пустая заготовка** «Атака титанов»                               |
| `demon-slayer/`      | **пустая заготовка** «Клинок, рассекающий демонов»                 |

У пустых заготовок уже заполнены название, описание, жанры и автор
(в файле `data/manga.js`). Остаётся положить картинки.

## Шаг 1. Структура папок

```
manga/
  chainsaw-man/          ← папка манги (латиница, как поле slug в data/manga.js)
    cover.jpg            ← обложка (можно .png или .webp)
    ch-1/                ← глава 1
      1.jpg              ← страница 1
      2.jpg              ← страница 2
      ...
    ch-2/                ← глава 2
      1.jpg
      ...
```

- Главы — папки `ch-1`, `ch-2`, `ch-3`... **без пропусков** (сайт ищет их по порядку).
- Страницы — `1.jpg`, `2.jpg`, `3.jpg`... тоже без пропусков.
  Подходят и другие варианты имён: `001.jpg`, `01.jpg`, `page (1).jpg`.
- Форматы: `jpg`, `jpeg`, `png`, `webp`, `gif`. Внутри одной главы — один формат.
- Файл `ПОЛОЖИТЕ_СЮДА_СТРАНИЦЫ.txt` можно удалить, он только подсказка.

## Шаг 2. Как сохранить страницы с сайта (например, mangalib.me)

1. Откройте нужную главу на сайте.
2. Нажмите **правой кнопкой мыши** на страницу → **«Сохранить картинку как...»**.
3. В окне сохранения перейдите в папку главы, например
   `MangaG\manga\chainsaw-man\ch-1`.
4. В поле «Имя файла» напишите номер страницы: `1` → «Сохранить».
   Следующую страницу — `2`, потом `3` и т.д.
   (Расширение браузер подставит сам.)
5. Обложку сохраните так же в папку манги под именем `cover`.

**Если файлы уже скачаны с «кривыми» именами:**
выделите их все в Проводнике (в правильном порядке, обычно это сортировка по
имени или по дате) → нажмите **F2** → введите `page` → **Enter**.
Windows переименует их в `page (1).jpg`, `page (2).jpg`, ... — сайт понимает такие имена.

> Если картинка сохраняется в формате `.webp` или `.avif` — `webp` подходит,
> а `avif` лучше пересохранить (например, открыть в Paint и «Сохранить как» JPG).

## Шаг 3. Проверка

Откройте `index.html` (или нажмите F5, если сайт уже открыт) → найдите мангу →
вкладка «Главы». Если страница не нашлась, читалка покажет, по какому пути она
её искала — сравните с именами ваших файлов.

## Как добавить новую мангу, которой нет в списке

1. Создайте папку `manga/<имя-латиницей>/`, например `manga/naruto/`.
2. Откройте `data/manga.js` в VS Code.
3. Скопируйте любой блок от `{` до `},` и вставьте в список. Поменяйте поля:

```js
  {
    slug: 'naruto',                  // ← имя папки
    name: 'Наруто',
    altName: 'Naruto',
    author: 'Масаси Кисимото',
    type: 'MANGA',                   // MANGA | MANHWA | MANHUA | COMIC
    status: 'COMPLETED',             // ONGOING | COMPLETED | FROZEN
    ageRating: 12,                   // 0, 12, 16, 18
    year: 1999,
    genres: ['action', 'adventure', 'martial-arts'],   // список — в data/genres.js
    description: 'Описание манги...',
  },
```

4. Сохраните файл (Ctrl+S) и обновите сайт (F5).

**Названия глав.** Если хотите, чтобы в списке было «Глава 1 — Узумаки Наруто»,
добавьте поле `chapters` (пример — у «Магической битвы» и «Перчинки» в `data/manga.js`):

```js
    chapters: [
      { number: 1, name: 'Узумаки Наруто' },
      { number: 2, name: 'Конохамару' },
    ],
```

Если `chapters` указан, сайт берёт главы только из этого списка (папки `ch-<номер>`).

**Скрыть мангу** не удаляя: добавьте в её блок `hidden: true,`.

## Частые ошибки

| Симптом                               | Причина и решение                                                         |
| ------------------------------------- | ------------------------------------------------------------------------- |
| Сайт открылся пустым / белым          | Ошибка в `data/manga.js`: пропущена запятая или кавычка. Откройте файл в VS Code — ошибка подчеркнётся красным. |
| «Главы ещё не добавлены»              | Нет папки `ch-1` или в ней нет файла `1.jpg` (`001.jpg`, `page (1).jpg`).  |
| Обрываются страницы на середине       | Пропущен номер: например, есть `5.jpg` и `7.jpg`, но нет `6.jpg`.          |
| Нет обложки                           | Файл должен называться `cover.jpg` / `cover.png` / `cover.webp`.            |
| Манги нет в каталоге                  | Не совпадает `slug` в `data/manga.js` и имя папки, или стоит `hidden: true`. |

## Про авторские права

Мангу с mangalib и других сайтов используйте **только для локальной демонстрации**
курсового проекта. Не выкладывайте такие папки в открытый доступ (публичный
репозиторий GitHub, GitHub Pages и т.п.). Комикс Pepper&Carrot можно
распространять свободно с указанием автора — см. `pepper-and-carrot/LICENSE.txt`.
