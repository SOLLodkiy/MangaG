# MangaG

**Платформа для художников комиксов и манги**: постраничный просмотр, система глав,
донаты автору. Ориентир по функционалу — [mangalib.me](https://mangalib.me/).

Курсовой проект. Автор: **Солодкий Максим**, группа **3ПО-9**.

## Запуск — без установки чего-либо

Сайт работает **полностью в браузере**: не нужны Node.js, сервер, база данных и интернет.

1. Скачайте проект:
   - на странице репозитория GitHub нажмите зелёную кнопку **Code → Download ZIP**,
     распакуйте архив (ПКМ → «Извлечь всё»);
   - или скопируйте папку проекта с флешки.
2. Откройте папку `MangaG` и **дважды щёлкните по файлу `index.html`**.
   Сайт откроется в браузере по умолчанию.

Если `index.html` открывается в VS Code, а не в браузере: в VS Code на файле
`index.html` нажмите ПКМ → **Reveal in File Explorer** (Показать в проводнике), затем
ПКМ по файлу → **Открыть с помощью → Google Chrome / Microsoft Edge / Яндекс Браузер**.
Можно и просто перетащить `index.html` в окно браузера.

> Работает в Chrome, Edge, Яндекс Браузере, Firefox, Opera. Расширение Live Server
> и другие плагины VS Code **не нужны**.

## Возможности

- **Каталог**: поиск, фильтры по жанрам, типу и статусу, сортировка, пагинация
- **Страница тайтла**: описание, рейтинг (оценки 1–10), закладки
  («Читаю», «В планах», «Прочитано», «Брошено», «Любимое»), список глав, комментарии
- **Читалка**:
  - постраничный режим и лента;
  - листание стрелками, A/D, кликом и свайпом;
  - направление справа налево для манги;
  - сохранение прогресса и кнопка «Продолжить»;
  - экран конца главы с лайком, донатом и комментариями
- **Донаты автору**: выбор суммы, сообщение, учебная платёжная форма
  (проверка карты по алгоритму Луна), история донатов, баланс и топ поддержавших
- **Кабинет автора**: создание тайтла, обложка, главы, загрузка страниц пачкой,
  изменение порядка страниц, черновики и публикация
- **Профиль**: аватар, «о себе», смена пароля, «Стать автором», закладки по спискам
- **Админка**: пользователи и роли, скрытие и удаление тайтлов, модерация комментариев, сброс данных
- Тёмная и светлая тема, адаптивная вёрстка для телефона

## Как это устроено

| Часть            | Где                       | Как работает                                              |
| ---------------- | ------------------------- | --------------------------------------------------------- |
| Интерфейс        | `index.html`, `css/`      | HTML + CSS, тёмная/светлая тема через CSS-переменные       |
| Логика           | `js/`                     | чистый JavaScript без библиотек и сборки                   |
| Маршруты         | `js/router.js`            | hash-адреса `#/title/...`, работают без сервера            |
| Каталог манги    | `data/manga.js`, `manga/` | список тайтлов + папки с картинками, главы ищутся автоматически |
| «База данных»    | `js/storage.js`           | `localStorage` браузера (пользователи, закладки, донаты...) |
| Картинки авторов | `js/images-db.js`         | `IndexedDB` (страницы, загруженные через кабинет автора)   |

Данные пользователей хранятся в браузере конкретного компьютера. Это учебная
имитация серверной части: оплата ненастоящая, пароли хешируются SHA-256 только
для примера.

## Структура проекта

```
MangaG/
├── index.html          # точка входа — открыть в браузере
├── css/style.css       # стили
├── img/logo.svg
├── data/
│   ├── genres.js       # жанры
│   └── manga.js        # ← список манги (редактируется вручную)
├── manga/              # ← картинки: обложки и страницы глав
│   └── КАК_ДОБАВИТЬ_МАНГУ.md
├── js/
│   ├── utils.js        # вспомогательные функции
│   ├── storage.js      # обёртка над localStorage
│   ├── images-db.js    # IndexedDB для картинок
│   ├── auth.js         # пользователи, вход, роли
│   ├── library.js      # тайтлы, главы, страницы, оценки, закладки
│   ├── ui.js           # модальные окна, уведомления, карточки
│   ├── router.js       # роутер
│   ├── comments.js     # комментарии
│   ├── donations.js    # донаты
│   ├── app.js          # запуск приложения
│   └── pages/          # страницы сайта
├── docs/               # материалы к пояснительной записке
└── CLAUDE.md           # план разработки
```
