## 1. Идея проекта

- **Читатели** находят мангу в каталоге и читают главы постранично, как на mangalib.
  Они добавляют тайтлы в закладки, ставят оценки, комментируют и поддерживают авторов донатами.
- **Авторы** создают тайтлы и загружают главы (набор картинок-страниц). Они управляют
  порядком страниц, публикуют главы и видят статистику и донаты.
- **Администратор** управляет пользователями, ролями и контентом.

Ключевые функции по теме:

1. **Система глав**: тайтл → тома → главы → страницы, черновик и публикация, навигация между главами.
2. **Постраничный просмотр**: режимы «страница» и «лента», клавиши, клики и свайпы,
   направление чтения, предзагрузка, сохранение прогресса.
3. **Донаты автору**: модальное окно с суммой и сообщением, учебная платёжная форма,
   история, баланс, топ поддержавших.

## 2. Главное ограничение и архитектура

**На учебном компьютере нельзя ничего устанавливать.** Есть только браузер и VS Code,
Node.js нет. Поэтому:

- сайт — **статический**, открывается **двойным кликом по `index.html`** (`file://`);
- **без сервера, без Node.js, без сборки, без CDN** (интернет тоже не обязателен);
- только `<script src>` (классические скрипты). **ES-модули (`type="module"`) и `fetch()`
  локальных файлов запрещены**: при открытии через `file://` браузер их блокирует;
- «серверная часть» имитируется в браузере:
  - `localStorage` — пользователи, закладки, оценки, комментарии, лайки, донаты;
  - `IndexedDB` — картинки, загруженные через кабинет автора;
- манга из файлов: описание в `data/manga.js` (`window.MANGA_LIBRARY = [...]`),
  картинки в `manga/<slug>/ch-N/1.jpg`. Главы и страницы **находятся автоматически**:
  сайт по очереди пробует загрузить картинки через `new Image()`, это работает и на `file://`.

> История: этапы 0–3 первой версии были сделаны на Node.js + Express + Prisma (REST API, JWT,
> тесты Jest). От них отказались из-за ограничения выше. Код остался в истории git:
> коммит `d9c9b79` («feat(server): titles CRUD, catalog with filters and demo seed»).

### Стек

| Слой      | Технология                                                 |
| --------- | ---------------------------------------------------------- |
| Разметка  | HTML5, одна страница `index.html`                          |
| Стили     | CSS3: переменные, grid/flex, тёмная и светлая тема, адаптив |
| Логика    | JavaScript (ES2020+), без фреймворков и библиотек          |
| Маршруты  | свой hash-роутер (`#/title/slug`)                          |
| Хранилище | `localStorage` (JSON) + `IndexedDB` (Blob картинок)        |
| Пароли    | SHA-256 через `crypto.subtle` (учебная имитация)           |
| Оплата    | учебная форма, проверка карты алгоритмом Луна              |

## 3. Структура

```
MangaG/
├── index.html              # единственная HTML-страница, подключает все скрипты по порядку
├── css/style.css
├── img/logo.svg
├── data/
│   ├── genres.js           # window.GENRES
│   └── manga.js            # window.MANGA_LIBRARY — тайтлы из файлов (редактирует пользователь)
├── manga/
│   ├── КАК_ДОБАВИТЬ_МАНГУ.md
│   ├── pepper-and-carrot/  # настоящий комикс, CC BY 4.0 (см. LICENSE.txt внутри)
│   ├── demo-*/             # демо-страницы в SVG
│   └── <slug>/             # заготовки реальной манги (пустые ch-1/)
├── js/
│   ├── utils.js            # Utils: esc, slugify, даты, plural, хеш, Луна, resizeImage
│   ├── storage.js          # Store: get/set/update над localStorage (префикс mangag_)
│   ├── images-db.js        # ImagesDB: put/get/remove/url над IndexedDB
│   ├── auth.js             # Auth: демо-пользователи, register/login/logout, роли
│   ├── library.js          # Library: тайтлы (file + local), главы, страницы, статистика, CRUD кабинета
│   ├── ui.js               # UI: toast, modal, confirm, cover, hydrate, titleCard, requireAuth
│   ├── router.js           # Pages = {} и Router (hash-маршруты, cleanup, isActive)
│   ├── comments.js         # Comments: список, добавление, ответы, удаление, render()
│   ├── donations.js        # Donations: создание, оплата, топ, openModal()
│   ├── pages/              # Pages.home, catalog, title, reader, login, register, profile,
│   │                       # donations, pay, studio, studioTitle, admin, help, notFound
│   └── app.js              # App: тема, шапка, регистрация маршрутов, старт
└── docs/
```

Порядок `<script>` в `index.html` важен: данные → ядро → компоненты → страницы → `app.js`.

## 4. Данные

### Тайтл (нормализованный, `Library.normalizeFile` / `normalizeLocal`)

```
{ source: 'file' | 'local', slug, name, altName, author, authorUserId, ownerId,
  type: MANGA|MANHWA|MANHUA|COMIC, status: ONGOING|COMPLETED|FROZEN,
  ageRating: 0|12|16|18, year, genres: [slug], description,
  cover (имя файла), coverKey (IndexedDB), createdAt, hidden, raw }
```

- `file`: из `data/manga.js`, только чтение; главы — из `raw.chapters` или автопоиском
  папок `ch-1..N`; страницы ищутся по шаблонам `1`, `001`, `01`, `page (1)` и расширениям
  `jpg png webp jpeg gif svg`.
- `local`: из кабинета автора (`Store 'titles'`), главы:
  `{ id, number, volume, name, published, publishedAt, pages: [ключи IndexedDB] }`.

### Ключи localStorage (префикс `mangag_`)

| Ключ        | Формат                                                                                    |
| ----------- | ----------------------------------------------------------------------------------------- |
| `users`     | `[{ id, email, username, role, bio, avatar(dataURL), balance, passwordHash, createdAt }]` |
| `session`   | id вошедшего пользователя                                                                  |
| `titles`    | тайтлы из кабинета автора                                                                  |
| `bookmarks` | `{ userId: { slug: 'READING' \| 'PLANNED' \| 'COMPLETED' \| 'DROPPED' \| 'FAVORITE' } }`  |
| `progress`  | `{ userId \| 'guest': { slug: { chapter, page, updatedAt } } }`                            |
| `ratings`   | `{ slug: { userId: 1..10 } }`                                                              |
| `comments`  | `[{ id, slug, chapter \| null, userId, text, parentId, createdAt }]`                       |
| `likes`     | `{ 'slug#chapter': [userId] }`                                                             |
| `views`     | `{ slug: n, 'slug#chapter': n }`                                                           |
| `donations` | `[{ id, fromUserId, toAuthor, toUserId, slug, titleName, amount(₽), message, status, ... }]` |
| `hidden`    | slug тайтлов из файлов, скрытых админом                                                   |
| `reader`    | настройки читалки `{ mode, direction, fit, bg, width }`                                    |
| `theme`     | `dark` \| `light`                                                                          |

## 8. Чек-лист приёмки

1. Двойной клик по `index.html` → открывается главная без ошибок в консоли (F12).
2. Гость: каталог → фильтр «Фэнтези» → «Перчинка и Морквик» → «Начать читать» → листает стрелками.
3. Регистрация → закладка «Читаю» → оценка 8 → комментарий и ответ на него.
4. Читалка: дочитать главу → экран конца главы → лайк → закрыть вкладку → открыть сайт →
   на главной «Продолжить чтение» ведёт на ту же страницу.
5. Настройки: лента и «справа налево», после перезагрузки настройки сохранились.
6. Донат 300 ₽ картой `4242 4242 4242 4242` → «Спасибо за поддержку!»; карта
   `4000 0000 0000 0002` → «Платёж отклонён»; донат виден в истории.
7. «Стать автором» → новый тайтл → обложка → глава → загрузка 3 файлов → смена порядка →
   публикация → глава читается.
8. Админ: смена роли, скрытие тайтла, удаление комментария.
9. Мобильная ширина (DevTools, 390px): всё читается, свайпы листают страницы.

## 9. Правила разработки (в т.ч. для ИИ-ассистента)

- **Никаких зависимостей, сборки и ES-модулей.** Сайт обязан работать через `file://`
  без интернета. Новый скрипт — отдельный `<script src>` в `index.html` в нужном месте.
- Глобальные объекты-модули: `Utils`, `Store`, `ImagesDB`, `Auth`, `Library`, `UI`,
  `Router`, `Pages`, `Comments`, `Donations`, `App`. Новая страница — функция
  `Pages.xxx = async (ctx) => {...}` в `js/pages/`, маршрут — в `App.init()`.
- `ctx = { app, params, query, path, isActive }`. После каждого `await` проверять
  `if (!ctx.isActive()) return;`. Страница может вернуть функцию очистки (снять обработчики).
- Обработчики вешать на элементы, созданные при рендере, **не на `#app`**: он живёт всё время,
  и обработчики на нём накапливались бы.
- Всё, что ввёл пользователь, выводить только через `Utils.esc()`.
- Картинки из IndexedDB: `<img data-idb="key">` + `UI.hydrate(root)`;
  обложки из файлов: `UI.cover(title)` (перебор `cover.jpg/png/webp`, иначе цветная заглушка).
- Данные менять только через методы модулей (`Library.*`, `Auth.*`, `Store.update`).
- Интерфейс на русском; имена в коде на английском, комментарии на русском.
- Код должен выглядеть как аккуратная студенческая работа: понятные имена, без переусложнения.
- Суммы донатов хранятся в целых рублях.
- Перед коммитом проверить сайт в браузере через `file://` (консоль без ошибок)
  и пройти затронутые пункты чек-листа.
- Копирайтная манга (mangalib и т.п.) **не коммитится** ассистентом. Пользователь кладёт
  её локально сам, только для демонстрации. В репозиторий попадает только свободный контент
  (Pepper&Carrot — CC BY 4.0, с указанием авторства).
